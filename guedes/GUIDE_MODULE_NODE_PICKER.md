# Guide: Module Node Picker

## Назначение
`Module Nodes` — это боковой инструмент для работы с нодами по модулям в ComfyUI:
- просмотр нод по группам,
- быстрый поиск модуля,
- отображение статусов обновлений,
- вставка нод в workflow в 1 клик.

## Где находится
- В современных версиях ComfyUI: вкладка `Module Nodes` в Sidebar.
- Если Sidebar API недоступен: fallback-кнопка `Module Nodes` в меню.

## Основной сценарий (быстрый)
1. Выберите группу: `Core_Nodes`, `Core_Extras_Nodes`, `API_Nodes`, `Custom_Nodes`.
2. Выберите модуль во втором списке (или через текстовый фильтр).
3. Нажмите на карточку модуля, чтобы открыть список нод.
4. Кликните нужную ноду — она вставится в центр видимой области workflow.

## Что показывает интерфейс
- 2 dropdown: группа + модуль.
- Поле фильтра модулей по подстроке.
- Карточка модуля: описание, owner, статус версии.
- Чекбокс `Debug` в заголовке: включает/скрывает диагностический блок (по умолчанию выключен).
- Статусные метки в списке модулей:
  - `✅` — модуль обновился между запусками ComfyUI,
  - `🟥` — для модуля подтверждено обновление по git (`behind > 0`).
- Подсветка нод в списке:
  - красная рамка — новая нода,
  - зеленая рамка — обновленная нода.

## Обновления модулей и ComfyUI
- `Обновить информацию о модулях` — пересчет статусов модулей, обновление кэша и списка.
- `Обновить информацию о ComfyUI` — отдельная проверка статуса ComfyUI.
- `Update module` — `git pull --ff-only` для выбранного custom-модуля.
- `Update all custom_nodes (N)` — обновление всех custom-модулей с available update.
- `Update ComfyUI` — обновление самого ComfyUI (`git pull --ff-only`).

## Работа с зависимостями
Если после update изменился `requirements.txt`, виджет предлагает установить зависимости.
Установка выполняется в том же Python-окружении, где запущен ComfyUI (`sys.executable`).

## Дополнительно
- Прогресс refresh выводится одной строкой в виджете, без консольного спама.
- При первом открытии виджет загружает статусы из кэша (без git-проверок).
- Проверка актуальных статусов и upstream выполняется только по кнопкам обновления внутри виджета.
- Метки новизны (`✅`, красные/зеленые рамки нод) сохраняются между перезапусками ComfyUI.
- Локальные изменения в модуле тоже учитываются как новизна между запусками:
  - новый локальный commit в модуле,
  - незафиксированные git-изменения в рабочей копии.
- Карточка модуля также подсвечивается зеленой рамкой, если модуль отмечен как обновленный между запусками.
- Метки новизны сбрасываются после явного действия:
  - `Обновить информацию о модуле` (только выбранный модуль),
  - `Обновить информацию о модулях` (все модули).
- Для ComfyUI действует аналогичная логика:
  - локальное обновление ComfyUI помечается и сохраняется между перезапусками,
  - `Обновить информацию о ComfyUI` сбрасывает эту метку и показывает актуальный статус.
- Для `Custom_Nodes` отображаются имена каталогов из `ComfyUI/custom_nodes` (без путей).
