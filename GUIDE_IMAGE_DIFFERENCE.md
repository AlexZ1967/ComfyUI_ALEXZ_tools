# Image Difference — краткий гайд

**Назначение:** быстро получить абсолютную разницу между двумя изображениями, чтобы контролировать сходство/расхождения. Подходит как самостоятельный инструмент и как вспомогательная проверка для других нод (Color Match, Video Frame Match и др.).

## Входы
- `image_a` — первая картинка (эталон).
- `image_b` — вторая картинка (для сравнения).
Если размеры разные, меньшая картинка автоматически приводится к размеру большей (по площади).

## Выходы
- `difference` — |A−B| в диапазоне 0–1, формат `IMAGE` (BHWC).

## Использование
1) Подайте два изображения. Если размеры различаются, нода автоматически приведет меньшее к большему.
2) Результат `difference` можно визуализировать или подать дальше в пайплайн (например, на JsonDisplayAndSave через stats/метрики).

## Советы
- Если дифф почти чёрный — изображения совпадают хорошо. Яркие области показывают локальные расхождения.
- Для сравнения перед/после цветокоррекции подайте эталон и результат обработки.
- Для проверки совпадения кадра из видео с референсом можно подать найденный кадр и целевое изображение (альтернатива встроенному difference в VideoFrameMatch).
