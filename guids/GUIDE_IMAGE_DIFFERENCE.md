# Image Difference — Guide

## Назначение
Вычисление абсолютной разницы между двумя изображениями: `difference = |A - B|`.

## Когда использовать
- Быстрый визуальный контроль изменений до/после обработки.
- Проверка качества выравнивания, цветокоррекции, frame match.

## Минимальный сценарий (3 шага)
1. Подайте `image_a` и `image_b`.
2. Получите `difference`.
3. Оцените яркие зоны как участки расхождения.

## Параметры
| Параметр | Что делает | Рекомендация |
|---|---|---|
| `image_a` | Первая картинка | Обычно эталон |
| `image_b` | Вторая картинка | Обычно результат |

Примечание: если размеры отличаются, меньшая картинка автоматически ресайзится к большей (по площади).

## Decision helper
- Сравнение до/после цветокоррекции -> `image_a=reference`, `image_b=matched`.
- Контроль выравнивания -> `image_a=background`, `image_b=aligned_overlay`.
- Контроль найденного видеокадра -> `image_a=target`, `image_b=best_frame`.

## Интерпретация выходов
- `difference`: изображение расхождений в диапазоне `[0..1]`.

Числовой ориентир (по среднему значению `difference.mean()`):
- `<0.03` — очень близко,
- `0.03-0.08` — умеренно,
- `>0.08` — заметное различие.

## Типовые ошибки и решения
- Картинки разного размера: нода обработает автоматически.
- Слишком яркий diff везде: проверьте, что сравниваете одинаковые по геометрии изображения.

## Производительность
- Узел очень лёгкий: одна операция `abs` + возможный ресайз.
