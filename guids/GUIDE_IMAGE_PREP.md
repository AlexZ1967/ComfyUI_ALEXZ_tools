# Image Prepare for QwenEdit Outpaint — Guide

## Назначение
Подготовка изображения под пайплайн Qwen Outpaint: ресайз под целевое соотношение сторон и генерация пустого латента для KSampler.

## Когда использовать
- Когда нужно быстро привести любой вход к удобному формату для outpaint.
- Когда нужен корректный latent того же батча и масштаба (/8).

## Минимальный сценарий (3 шага)
1. Подайте `image`.
2. Выберите `aspect_ratio`.
3. Используйте выходы `image` и `latent` в следующем узле генерации.

## Параметры
| Параметр | Что делает | Практический выбор |
|---|---|---|
| `image` | Исходное изображение | Любой `IMAGE` (BHWC) |
| `aspect_ratio` | Целевой формат | `as_is` для сохранения пропорций, фиксированные пресеты для точного кадра |

## Decision helper
- Нужна максимальная естественность без жёсткого кадра -> `as_is`.
- Нужен вертикальный outpaint -> `9x16`.
- Нужен горизонтальный outpaint -> `16x9`.
- Нужен нейтральный квадратный формат -> `1x1`.

## Интерпретация выходов
- `image`: подготовленное изображение.
- `latent`: пустой latent (`4 x H/8 x W/8`) под KSampler.

## Типовые ошибки и решения
- Не тот итоговый размер: проверьте `aspect_ratio`.
- Дальше по цепочке ошибка по latent shape: убедитесь, что downstream-нода ожидает стандартный latent /8.
- Потеря деталей: дайте более качественный исходник (PNG вместо сжатого JPG).

## Производительность
- Узел лёгкий, один ресайз.
- На больших изображениях основная стоимость — интерполяция; обычно узкое место не здесь.
