# План выделения Silent Film в отдельный ComfyUI-модуль

## Цель и границы

Создать самостоятельный custom node package для Silent Film, который можно включать и обновлять отдельно от `ComfyUI_ALEXZ_tools`. Существующие workflow должны продолжить находить ноды по прежним `class_type`; интерфейсы входов/выходов, имена портов, `film_json`, bypass и previews сохраняются.

Предварительное имя пакета: `ComfyUI_ALEXZ_SilentFilm`. Имя и отдельный Git remote можно уточнить перед публикацией; локальное выделение не должно зависеть от наличия remote.

В модуль входят:

- 13 нод Cadence, Finish, Camera, Negative, Print, Projector и семи видов дефектов;
- загрузка и сохранение видео, выбор диапазона кадров и среднее preview, поскольку сейчас эти узлы встроены в пайплайн и импортируют его валидатор;
- специфичные для плёнки расчёт памяти и выборочное кэширование;
- сенситометрия, оптика, генерация дефектов и относящиеся к ним API маршруты;
- frontend-расширения, TS-исходники и сгенерированные runtime bundles;
- документация, workflows-примеры и относящиеся к модулю тесты.

Общие ALEXZ-функции (менеджер нод, обновления, сохранение workflow проекта и несвязанные ноды) остаются в `ComfyUI_ALEXZ_tools`. Низкоуровневый код видеокодирования переносится в новый пакет либо получает локальную реализацию/адаптер, чтобы модуль не требовал импорта внутренних модулей ALEXZ_tools.

## Безопасные ограничения

1. Не менять существующие `class_type`, названия, входы/выходы и сериализуемые поля нод.
2. Не допускать регистрации одного `class_type` одновременно из двух custom-node пакетов.
3. Не изменять ComfyUI core. Кэш-адаптер должен оставаться узким и включаться только при загрузке Silent Film.
4. Не перезаписывать пользовательские workflows и локальные файлы. Переносить только отслеживаемые проектные примеры после явной сверки.
5. Не переносить вручную generated TypeScript output: собирать его пользовательской командой; при необходимости синхронизировать отслеживаемые runtime bundles по принятому процессу проекта.
6. Проверки, сборки и browser smoke запускает пользователь.

## Последовательность

### Этап 1. Зафиксировать границу общих видеоконтрактов — выполнен

- IMAGE batch validation сначала вынесен в нейтральный helper, а затем helper перенесён в новый пакет вместе со всеми потребителями.
- Общие ALEXZ-ноды больше не импортируют Film Finish; сейчас в ALEXZ_tools не осталось Film Finish и video I/O потребителей этого контракта.

### Этап 2. Создать самостоятельный пакет и его регистрационный каркас — выполнен

- Создан соседний Git-репозиторий `ComfyUI_ALEXZ_SilentFilm`, с собственным entry point, реестром и `WEB_DIRECTORY`.
- Владение 17 `class_type` переключено на новый пакет; ALEXZ_tools больше их не регистрирует.
- Новый пакет самостоятельно включает video routes и selective output cache. ComfyUI core не изменён.
- Отдельный Git remote пока не назначен.

### Этап 3. Перенести backend ноды и алгоритмы — выполнен

- Перенести узлы Silent Film и film utilities, разорвав импорты на приватные модули ALEXZ_tools.
- Перенести/адаптировать video I/O, выбор кадров, previews, memory planner и output cache.
- Маршруты регистрировать из entry point нового модуля и не дублировать маршруты основного плагина.
- Backend-файлы и локальные утилиты скопированы в standalone package; пакет не импортирует внутренние модули ALEXZ_tools.
- Реестр и UI metadata активны; импортов во внутренние модули ALEXZ_tools нет.

### Этап 4. Перенести frontend — выполнен

- Перенести JS и TS исходники расширений, подключить сборку внутри нового пакета.
- Сохранить ComfyUI extension IDs и поведение UI там, где совместимость этого требует.
- Проверить путь к runtime bundles и независимую загрузку web assets.
- TS/JS исходники, изолированная сборка и runtime bundles находятся в новом пакете; в ALEXZ_tools убраны дубликаты, visibility profiles разделены по нодам.

### Этап 5. Перенести документацию, fixtures и workflow-примеры — выполнен
