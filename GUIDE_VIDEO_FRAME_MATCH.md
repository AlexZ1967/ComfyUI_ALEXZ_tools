# Find Closest Video Frame — Guide

## Назначение
Поиск кадра в видео, максимально похожего на заданное изображение. Доступны метрики: MSE, SSIM, LPIPS, CLIP.

## Быстрый старт
1) `image` — целевой кадр.  
2) `video` — выберите файл из input/.  
3) `max_frames=0` чтобы пройти всё видео, или ограничьте (напр. 500), чтобы анализировать только последние кадры.  
4) `metric=mse` для быстрого точного сравнения, `ssim` устойчивее к яркости, `lpips/clip` — более «перцептивные».  
Получите `best_frame`, `best_index`, `best_score`, `scores_json`.

## Параметры
- `max_frames`: количество последних кадров для анализа (0 = без лимита).  
- `metric`: `mse` / `ssim` / `lpips` / `clip`.  
- `normalize`: `none` / `mean_std` / `linear` / `hist` (приводит кадр к цвету референса перед сравнением).  
- `metric_size`: если >0, ресайз обеих картинок к квадрату (ускоряет метрики).  
- `lpips_net`: `vgg` (качество) / `alex` (быстрее).  
- `clip_model`, `clip_pretrained`: параметры open_clip.  

## Выходы
- `best_frame`: кадр, наиболее похожий на картинку.  
- `difference`: |best_frame - image| для визуального контроля.  
- `best_index`: номер кадра (с нуля).  
- `best_score`: значение выбранной метрики (меньше = лучше).  
- `scores_json`: объект `{metric, normalize, scores}` с первыми 500 оценками `{index, score}`.

## Рекомендации
- Если видео большое, ограничьте `max_frames`, чтобы ускорить поиск.  
- Чем ближе размер картинки к размеру кадра, тем корректнее оценка; resize внутри узла линейный.  
- Для различий по яркости/контрасту используйте `ssim` или `normalize=mean_std`.  
- Для сложных случаев и «перцептивной» похожести используйте `lpips` или `clip` (медленнее).
