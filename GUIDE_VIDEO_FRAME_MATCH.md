# Find Closest Video Frame — Guide

## Назначение
Поиск кадра в видео, максимально похожего на заданное изображение. Метрика — MSE после приведения кадра к размеру картинки.

## Быстрый старт
1) `image` — целевой кадр.  
2) `video` — выберите файл из input/.  
3) `max_frames=0` чтобы пройти всё видео, или ограничьте (напр. 500), чтобы анализировать только последние кадры.  
Получите `best_frame`, `best_index`, `best_score`, `scores_json`.

## Параметры
- `max_frames`: количество последних кадров для анализа (0 = без лимита).  

## Выходы
- `best_frame`: кадр, наиболее похожий на картинку.  
- `difference`: |best_frame - image| для визуального контроля.  
- `best_index`: номер кадра (с нуля).  
- `best_score`: MSE (меньше = лучше).  
- `scores_json`: список первых 500 оценок `{index, mse}` для отладки/визуализации.

## Рекомендации
- Если видео большое, ограничьте `max_frames`, чтобы ускорить поиск.  
- Чем ближе размер картинки к размеру кадра, тем корректнее оценка; resize внутри узла линейный.  
- Для «почти одинаковых» кадров MSE хорошо показывает близость; для разных экспозиций/цветов можно предварительно нормализовать картинку (например, через Color Match).
