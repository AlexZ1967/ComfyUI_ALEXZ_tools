# Show/Save JSON — Guide

## Назначение
Форматированный вывод JSON в UI и опциональное сохранение в файл.

## Когда использовать
- Нужно читать `transform_json` и другие служебные payload внутри графа.
- Нужно сохранить JSON результат рядом с выходными файлами.

## Минимальный сценарий (3 шага)
1. Подайте `json_text` (строка/объект/список).
2. Укажите `output_path` (опционально).
3. Используйте UI-вывод и/или сохраненный файл.

## Параметры
| Параметр | Что делает | Рекомендация |
|---|---|---|
| `json_text` | Входной JSON | Можно подавать строку или объект |
| `output_path` | Куда сохранить JSON | Файл или директория (создаст `transform.json`) |

## Decision helper
- Нужен только просмотр -> оставьте `output_path` пустым.
- Нужно сохранять для NLE/скриптов -> задайте директорию результата.
- На входе часто сырые строки -> просто подайте как есть, нода сама попробует распарсить.

## Интерпретация выходов
- Выходных портов нет: нода работает как `OUTPUT_NODE` и показывает prettified JSON в UI.
- При заданном `output_path` тот же prettified JSON записывается в файл.

Пример:
```json
{"status":"ok","scale":[1.02,1.01,0.99]}
```

## Типовые ошибки и решения
- Строка не парсится: нода вернёт `raw` как есть.
- Не сохраняется файл: проверьте права и путь `output_path`.

## Производительность
- Узел лёгкий; основная стоимость — сериализация больших JSON.
