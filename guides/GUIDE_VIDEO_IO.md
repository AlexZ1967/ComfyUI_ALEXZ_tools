# Загрузка исходного и сборка финального видео ALEXZ

## Назначение

**Load Source Video (ALEXZ)** (`VideoLoadSource`) читает видео через FFmpeg, включая MOV/ProRes и MXF, сразу выбирая нужные кадры. **Save Final Video (ALEXZ)** (`VideoSaveFinal`) записывает обработанный IMAGE в ProRes/MOV или H.264/MP4. Категория обеих нод — `video/io`.

Нужны доступные в окружении ComfyUI `ffmpeg` и `ffprobe`. Ноды ничего не устанавливают автоматически. В текущем `p313-torch214-cu132` проверен FFmpeg 8.0.1 с `prores_ks` и `libx264`.

## Когда использовать

- Исходник записан в ProRes, нужно сохранить больше 8 бит при декодировании.
- Нужен один кадр или фрагмент без загрузки всего ролика в RAM.
- Нужен монтажный мастер ProRes либо компактный файл MP4.
- Нужно заменить VHS Load + Select Video Frames одной нодой в Silent Film.

Ноды работают с видеорядом **без звука**. Они не выполняют автоматическую обработку Log/HDR, deinterlace или преобразование в линейный свет. Пиксельные пропорции анаморфного видео не раскрываются; для него подготовьте квадратные пиксели заранее. Повороты 90/180/270 градусов учитываются.

## Минимальный сценарий (3 шага)

1. После перезапуска ComfyUI откройте [Видео-в-Хронику-по-этапам.json](../workflows/Видео-в-Хронику-по-этапам.json). Укажите `video_path` либо нажмите **Выбрать видео…**. Абсолютный путь, например к файлу в Загрузках, открывает его непосредственно. Выбор через системное окно копирует файл потоково в `ComfyUI/input/alexz_video`, не перезаписывая существующие файлы.
2. Нажмите **Load and calculate frame**. Информация о кодеке, формате пикселей, размерах, fps и числе кадров появится сверху; workflow не ставится в очередь. Выберите `single_frame` для цветокоррекции, `frame_range` для динамики или `full_video` для финала. При отсутствии счётчика в контейнере выполняется проход `ffprobe -count_frames` без хранения изображений; он может занять время.
3. Соедините `image` с Camera, затем Negative → Print → Projector → Save Final Video. Соедините **Projector.fps → Save.frame_rate**, выберите профиль и запустите workflow. Мастер и, при необходимости, MP4-превью появятся в `ComfyUI/output`.

## Параметры

### Load Source Video

| Параметр | Значение и настройка |
|---|---|
| `video_path` | Абсолютный локальный путь либо относительный путь внутри ComfyUI/input. Большой файл, уже находящийся на сервере, выгоднее открыть по пути без повторного копирования |
| `selection_mode` | `full_video` — весь файл, без дополнительных полей; `single_frame` — только `frame_index`; `frame_range` — только `start_frame` и `end_frame` |
| `frame_index` | Номер кадра с нуля. При 193 кадрах доступно 0–192; средний — 96 |
| `start_frame`, `end_frame` | Диапазон включительно. 24–47 даёт 24 кадра; `end_frame=-1` означает до конца |

Поле выбора режима, номера и границы соответствуют прежней Select Video Frames. Отдельная старая нода остаётся доступной для готовых IMAGE-батчей. Новый загрузчик не требует её установки после себя.

Декодер отдаёт выбранные кадры как 16-битный RGB/RGBA, затем преобразует в float32 с диапазоном 0–1. Это избегает промежуточного RGB8; исходное 8-битное видео не получает дополнительной точности. RGBA сохраняется для форматов с альфой. Число кадров определяется по контейнеру либо точным подсчётом, без оценки `duration × fps` при основном запуске.

Границы задаются по порядку декодированных кадров, а не приблизительному seek по секундам. Чтобы дойти до позднего диапазона, FFmpeg может декодировать предыдущие кадры, но они не накапливаются в RAM и не передаются в пайплайн. Для VFR возвращается средняя частота файла; индивидуальные timestamps не переносятся в IMAGE, сборка выполняется с постоянной заданной частотой.

### Save Final Video

| Параметр | Значение и настройка |
|---|---|
| `image` | Готовый RGB/RGBA-батч, включая GPU и дисковое хранение |
| `frame_rate` | Частота готового видео. Для Silent Film подключайте Projector.fps, обычно 25. Длительность = число кадров / frame_rate |
| `filename_prefix` | Имя и подпапка внутри output, например `ALEXZ/SilentFilm`. К нему добавляется свободный номер; прежние файлы не заменяются |
| `format` | Профиль ProRes MOV либо `h264_mp4`; подробнее ниже |
| `crf` | Только H.264; ниже — выше качество и размер. Старт 18–19. На CPU применяется CRF `libx264`; если вход в VRAM и доступен NVENC, используется его Constant Quality со схожим назначением, но другой шкалой. Поле скрыто при ProRes |
| `create_preview` | Для ProRes создаёт отдельный H.264 MP4 до 960 px для браузера. Мастер MOV сохраняется без уменьшения. Для H.264 показывается сам файл |

| `format` | Назначение |
|---|---|
| `prores_422_proxy` | Небольшая монтажная копия; заметнее потери |
| `prores_422_lt` | Компромисс размера и качества |
| `prores_422` | Обычный монтажный ProRes 422 |
| `prores_422_hq` | Рекомендуемый старт для финального мастера; лучше сохраняет сложное зерно, файл больше |
| `prores_4444`, `prores_4444_xq` | Цвет без субдискретизации и сохранение альфы RGBA; XQ даёт более высокий битрейт |
| `h264_mp4` | Компактный просмотр/публикация, 8 бит, 4:2:0. Нужны чётные ширина и высота |

Установленный `prores_ks` принимает YUV 10 бит: экспорт 4444 не является обещанием 12-битного цвета. Альфа 4444 кодируется отдельно. Форматы без альфы накладывают RGBA на чёрный фон. Экспорт рассчитан на SDR Rec.709; для исходников Log/HDR требуется осознанное преобразование до художественной обработки.

## Decision helper

- Быстрая настройка: один средний кадр в загрузчике; смотрите выходы preview этапов.
- Проверка движения: диапазон 24–48 кадров; сохраняйте H.264 или ProRes LT.
- Финальный мастер с зерном: ProRes 422 HQ, `create_preview=true` для браузера.
- Прозрачный материал: ProRes 4444 и четырёхканальный вход.
- Быстрее записать только мастер: выключите `create_preview`.

`Load.fps` — фактическая средняя частота файла. `Camera.source_fps` может отличаться для компенсации рапида. В примере сохранено прежнее художественное значение 36; не заменяйте его автоматически на fps файла. `Save.frame_rate` берётся из Projector, а не из исходника.

## Интерпретация выходов

| Нода | Выходы |
|---|---|
| Load Source Video | `image`: выбранные кадры; `fps`: частота исходника; `total_frames`: весь файл; `selected_frames`: выбранное число; `video_json`: метаданные и границы; `preview`: средний выбранный кадр |
| Save Final Video | `video_path`: путь к мастер-файлу; `video_json`: формат, fps, размеры, длительность и путь MP4-превью. В самой ноде показывается браузерный плеер |

## Производительность

Загрузчик сохраняет только выбранные кадры в управляемом IMAGE-хранилище; крупный CPU-батч уходит в дисковый mmap-кэш. Сборщик читает по одному кадру, в том числе из VRAM, без полной CPU-копии видео. Изменения source-файла по размеру или mtime инвалидируют кэш ComfyUI. Подробности временного хранения — в [гайде Silent Film](GUIDE_VIDEO_SILENT_FILM_PIPELINE.md#хранение-батчей-и-предварительная-оценка-памяти).

ProRes мастер кодируется средствами CPU FFmpeg: `prores_ks` не использует NVENC. Для H.264 MP4 при CUDA-входе и доступном устройстве выбирается аппаратный `h264_nvenc`; иначе используется `libx264`. MP4-превью ProRes тоже использует NVENC, если он доступен. В обоих случаях сборщик подаёт кадры FFmpeg по одному, не копируя весь батч в RAM. При NVENC кадры проходят через CPU pipe и затем загружаются в GPU-кодировщик, поэтому это не полностью безкопийный путь из VRAM. Большой мастер требует места в output, дополнительно к временному IMAGE-кэшу. Сборка ведётся во временный файл, который публикуется после успешного завершения FFmpeg; при ошибке пустой результат удаляется. Ошибка создания необязательного превью не удаляет успешно записанный мастер и отображается в логе и video_json.

## Типовые ошибки и решения

| Симптом | Решение |
|---|---|
| Информация возвращает 404 | Перезапустите ComfyUI после обновления backend и обновите страницу |
| MOV не проигрывается непосредственно в браузере | Используйте MP4-превью; поддержка кодирования ProRes не означает поддержку воспроизведения браузером |
| Не найден ffmpeg/ffprobe или Unknown encoder | Проверьте FFmpeg в окружении запуска; нужны prores_ks и libx264 |
| Открывается не тот файл | Проверьте video_path; выбор кнопкой создаёт копию в input/alexz_video |
| Загрузка большого файла не завершилась | Проверьте место в input и доступность соединения. На этой же машине используйте абсолютный путь без загрузки |
| Неверная длительность | Проверьте выбор кадров, Camera.source_fps и связь Projector.fps → Save.frame_rate |
| Цвет отличается у Log/HDR | Ноды не выполняют автоматическое преобразование Log/HDR в SDR |
| Нечётный размер H.264 | Выберите ProRes либо приведите размеры к чётным перед записью |
| Видео получилось без звука | Эти ноды предназначены для видеоряда; аудиомонтаж выполняется отдельно |
