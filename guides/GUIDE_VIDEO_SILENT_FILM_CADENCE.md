# Silent Film Cadence — Guide

## Назначение
Имитация немого плёночного каденса: виртуальная съёмка с пониженным fps, неравномерной скоростью и экспозиционным motion blur. Это художественная модель ручного привода, а не точная реконструкция конкретного киноаппарата.

## Когда использовать
- Нужно сделать современный 25 fps исходник более похожим на съемку 1920-х.
- Нужно оставить длину клипа и совместимость с downstream-нодами на 25 fps.
- Нужна циклическая пульсация скорости ручки или прежний случайный дрейф fps.

## Минимальный сценарий (3 шага)
1. Подайте батч кадров в `image` и оставьте `source_fps=25`.
2. Выберите `playback_mode`: для аутентичного ускорения движения используйте `undercrank_projected_25fps`.
3. Настройте `shutter_fraction` и `motion_blur_strength`, затем проверьте `cadence_json.average_effective_fps`.

Для ручного привода дополнительно выберите **`cadence_model=hand_crank`**. Стартовые значения: `crank_irregularity=0.15`, `fps_drift_strength=0.65`, `camera_shake_strength=0.25`. Прежний `legacy_random` остаётся по умолчанию для совместимости старых workflow и вызовов без новых входов.

## Настройка ручки

| Настройка | Понятный смысл | Старт |
|---|---|---|
| `cadence_model` | `hand_crank` — цикл вращения; `legacy_random` — прежний сглаженный случайный дрейф | `hand_crank` |
| `fps_drift_strength` | Сила пульсации: `0` — постоянная средняя скорость; `1` — полная амплитуда диапазона fps | `0.65` |
| `crank_irregularity` | Плавная неровность темпа между оборотами. `0` — точно повторяющийся цикл; `1` — заметный дрейф с сохранением цикла | `0.10–0.25` |
| `camera_shake_strength` | Покачивание камеры при съёмке, связанное с ручкой. `0` — выключено, `1` — сильное | `0.15–0.30` |

Границы `target_fps_min/max` задают допустимую скорость, а `fps_drift_strength` — насколько сильно она меняется вокруг середины диапазона. При одинаковых границах либо нулевой силе скорость постоянна. Настройки ручки не влияют на `legacy_random`.

Фаза связана с продвижением плёнки, передаточное отношение фиксировано: 8 кадров на оборот. Каждый виртуальный кадр продвигает ручку на 1/8 оборота. При 16 fps получается примерно 2 оборота в секунду виртуальной съёмки; при 20 fps — примерно 2.5. В ускоренной проекции на 25 fps оборот занимает 8/25 секунды экранного времени. Отдельно задавать скорость ручки не нужно.

`crank_frames_per_turn` больше не является пользовательской настройкой: его виджет скрыт, сохранённое значение игнорируется, применяется фиксированное 8. Техническое поле оставлено на прежнем месте, чтобы значения остальных виджетов в сохранённых workflow не сдвигались.

Внутри оборота скорость изменяется плавно. Между оборотами может дрейфовать средний темп, но циклическая составляющая всегда остаётся основной. Экспозиция автоматически следует длительности виртуального кадра; независимый случайный сдвиг её центра в `hand_crank` отключён. `seed` задаёт начальную фазу и воспроизводимую нерегулярность.

## Покачивание при съёмке и дрожание проектора

`camera_shake_strength` добавляет небольшой сдвиг и наклон изображения по фазе ручки. Преобразование применяется к каждому отсчёту внутри экспозиции **до усреднения**, поэтому движение камеры даёт собственный смаз даже на неподвижном исходнике. При короткой экспозиции остаётся преимущественно покачивание, при длинной добавляется размытие вдоль траектории. При `blur_samples=1` траектория экспозиции не интегрируется — используется одно положение камеры.

Сила задаётся относительно размера кадра: уменьшенный preview сохраняет примерно тот же относительный размах. Это приближение небольшого движения камеры в плоскости изображения, без реконструкции глубины и параллакса. Края заполняются граничными пикселями, а не чёрным цветом.

Начните с `0.25`, для устойчивой камеры используйте `0–0.10`. Даже равномерная ручка может покачивать камеру: `fps_drift_strength=0` не отключает `camera_shake_strength`. В режиме `legacy_random` покачивание не применяется; настройки ручки скрыты. По умолчанию сила равна `0`, чтобы не менять ранее сохранённый результат.

`gate_weave_px` в Silent Film Finish — независимая нестабильность проекции. Её можно оставить около `0.5–0.8`, не пытаясь заменить ею движение камеры при съёмке.

## Параметры
| Параметр | Что делает | Рекомендация |
|---|---|---|
| `image` | Батч кадров в формате THWC | Обычно декодированный 25 fps клип |
| `source_fps` | FPS исходного батча и выходного батча | Для задачи немого кино обычно `25` |
| `playback_mode` | Режим воспроизведения | `undercrank_projected_25fps` для реального ускорения немого кино; `preserve_duration_25fps` если длину клипа нужно сохранить |
| `target_fps_min` | Нижняя граница виртуального low-fps захвата | `16` для более старой пластики |
| `target_fps_max` | Верхняя граница виртуального low-fps захвата | `18-20` для более мягкого результата |
| `fps_drift_strength` | Сила циклической пульсации в `hand_crank` или случайного дрейфа в `legacy_random` | `0.4-0.75` обычно достаточно |
| `shutter_fraction` | Какая доля интервала идет в blur-экспозицию | `0.8-1.0` для аутентичного smear |
| `motion_blur_strength` | Сила темпорального размытия | `0.7-1.0` как старт |
| `blur_mode` | Алгоритм motion blur | `simple` для скорости, `flow_integrated` для более мягкой длинной экспозиции без явной сдвоенности |
| `blur_samples` | Сколько суб-сэмплов усреднять | `5-9` обычно достаточно |
| `seed` | Детерминирует плавающий fps | Меняйте для другого микроритма |

## Decision helper
- Нужна настоящая пластика старой проекции -> `playback_mode=undercrank_projected_25fps`, а в `Video Combine` оставьте `25 fps`.
- Нужно сохранить длительность исходного клипа -> `playback_mode=preserve_duration_25fps`.
- Видна сдвоенность/строенность на движении -> переключитесь на `blur_mode=flow_integrated`.
- Нужен более нервный, дерганый ритм -> уменьшайте `target_fps_max` и `motion_blur_strength`.
- Нужна более мягкая, дорогая имитация -> держите `target_fps_max=18-20`, `shutter_fraction=0.9-1.0`, `blur_samples=7-9`.
- Слишком заметна тряска при съёмке -> уменьшите `camera_shake_strength`; частота движения автоматически связана с fps.
- Ритм слишком правильный -> поднимите `crank_irregularity` с `0.15` до `0.25`; для точного повторения поставьте `0`.
- Получается слишком современно -> уменьшайте диапазон к `16-18` и увеличивайте `fps_drift_strength`.
- Получается слишком смазано -> уменьшайте `motion_blur_strength` или `shutter_fraction`.

## Интерпретация выходов
- `image`: в режиме сохранения длины — батч той же длины; в ускоренной проекции — обычно укороченный батч.
- `cadence_json`: JSON-диагностика по реальному effective fps, hold-группам и параметрам blur.
- `cadence_json.actual_blur_mode`: фактический режим blur (`flow_integrated`, `simple` или fallback).
- `cadence_json.output_duration_seconds`: в `undercrank_projected_25fps` обычно меньше исходной длительности, это и дает ощущение ускоренной старой проекции.
- `cadence_json.group_count`: сколько виртуальных low-fps кадров получилось.
- `cadence_json.average_effective_fps`: фактический средний fps виртуального захвата.
- `cadence_json.group_sizes_preview`: размеры hold-групп, показывают где кадры повторялись по 1 или 2 раза.
- `cadence_json.fps_values_preview`: первые значения плавающего fps внутри клипа.
- `cadence_json.cadence_model`, `crank_irregularity`: выбранная модель и нерегулярность; `crank_frames_per_turn` сообщает фиксированное передаточное отношение.
- `camera_shake_strength`, `actual_camera_shake_strength`, `capture_motion_model`: заданная и фактическая сила покачивания и его модель (`crank_locked` или `none`).
- `cadence_json.phase_biases_full`: в `hand_crank` нулевые; случайный сдвиг экспозиции не добавляется.

Передайте `image` и `cadence_json` в Silent Film Finish. Формат синхронизации сохранён; успешное подключение отмечается как `finish_json.sync_mode=cadence_locked`.

Частоту готового файла задаёт `Video Combine`, а не имя режима. Для сохранения длительности используйте fps из `source_fps`; для ускоренной проекции — выбранные 25 fps. Если исходник действительно замедлен вдвое, можно интерпретировать весь батч с удвоенным `source_fps` (48 вместо 24), без отдельного ускорения ×2. При сборке на 25 fps фактическая длительность равна `output_frame_count / 25`; поле `output_duration_seconds` текущей ноды рассчитано по `source_fps`.

Пример:
```json
{
  "actual_blur_mode": "flow_integrated",
  "average_effective_fps": 17.2,
  "group_count": 172,
  "output_duration_seconds": 6.88,
  "group_sizes_preview": [2, 1, 2, 1, 1, 2],
  "fps_values_preview": [17.6, 18.1, 16.9, 17.2]
}
```

## Типовые ошибки и решения
- Клип почти не изменился: уменьшите `target_fps_max` и проверьте, что `source_fps` действительно `25`.
- Движение все еще слишком “современное”: переключитесь на `playback_mode=undercrank_projected_25fps`.
- Слишком заметны повторы: увеличьте `motion_blur_strength` или `shutter_fraction`.
- Слишком мало плавающего ритма: увеличьте `fps_drift_strength` или смените `seed`.
- Слишком много blur на движении: уменьшите `motion_blur_strength` до `0.5-0.7`.

## Производительность
- `simple` использует временное смешивание; `flow_integrated` требует OpenCV и проверяет согласованность потока, переходя к обычному смешиванию в ненадёжных областях.
- Генератор ручки не требует дополнительных моделей или frontend-сборки.
- Основная стоимость растет с `blur_samples`: `7` обычно дает хороший компромисс.
- Батчи с альфа-каналом тоже поддерживаются, альфа размывается тем же темпоральным интегрированием.
