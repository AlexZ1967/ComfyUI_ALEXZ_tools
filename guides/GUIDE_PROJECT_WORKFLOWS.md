# Сохранение workflow в выбранную папку и в проект

## Назначение

Раздел **Save Workflow** в левой панели поддерживает два назначения:

- **Сохранить как…** — стандартный системный диалог браузера: выберите папку и имя JSON-файла.
- **Сохранить** — повторно записывает в выбранный файл этого workflow. Если файл ещё не выбран, открывается тот же системный диалог.
- **Сохранить в workflows проекта** — прежний отдельный вариант записи через backend в папку ALEXZ_tools.

Обычные Save / Ctrl+S в ComfyUI продолжают работать с пользовательской библиотекой. Новые действия не меняют стандартное сохранение и не делают commit/push. Рендер при сохранении не запускается.

### Стандартный выбор папки

1. Откройте раздел **Save Workflow** слева и нажмите **Сохранить как…**.
2. В системном окне выберите нужную папку и новое имя либо существующий JSON для перезаписи.
3. Дождитесь сообщения **Сохранено: имя.json**. Дальнейшие изменения в этом workflow записывайте кнопкой **Сохранить**; для другой папки или файла снова используйте **Сохранить как…**.

Файлы записываются на компьютере браузера. Если сервер ComfyUI работает на другой машине, это не его произвольный каталог. Полный путь браузер приложению не раскрывает, поэтому в статусе отображается имя выбранного файла.

Выбранный файл запоминается отдельно для каждого открытого графа, пока страница открыта. После обновления страницы его нужно выбрать заново; браузер может запомнить последнюю папку системного диалога. Сам импорт через перетаскивание не передаёт право автоматически перезаписывать исходный JSON: первый выбор файла всё равно нужен.

Используется [File System Access API — документация Chrome](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access). Возможность проверяется в браузере; обычно доступна в Chromium-браузере на localhost или HTTPS. Если API отсутствует, интерфейс сообщает об этом: используйте стандартный Export и включите в настройках загрузок браузера запрос папки, чтобы избежать автоматического скачивания в Downloads.

Отмена системного диалога не сохраняет граф и не заменяет ранее выбранный файл. При повторной записи проверяются размер и время изменения файла; если его изменило другое приложение, операция останавливается. Для осознанной перезаписи выберите файл заново через Сохранить как…. Это проверка обычных внешних изменений, а не блокировка файла от одновременной работы других программ.

## Когда использовать

- Настроили параметры нод и хотите обновить общий workflow проекта.
- Нужно сохранить вариант рядом с примерами ALEXZ_tools.
- Workflow открыт перетаскиванием JSON, поэтому браузер не может штатно перезаписать исходный файл на диске.

## Минимальный сценарий (3 шага)

Для отдельного варианта записи именно в папку проекта:

1. Откройте **Save Workflow** в левой панели ComfyUI и нажмите **«Сохранить в workflows проекта»**. В версиях интерфейса с общим меню также доступна команда **File → Сохранить в workflows проекта**.
2. Выберите существующий JSON в списке **«Файл проекта»** либо задайте новое имя в **«Имя JSON-файла»**. Под полем показано, какой файл будет создан или перезаписан.
3. Нажмите **«Сохранить»** и дождитесь сообщения **«Сохранено: workflows/имя.json»**. Затем закройте окно.

Сохраняется граф активного workflow целиком, включая параметры, связи, расположение и определения подграфов. Рендер не запускается. Список файлов загружается только при открытии окна, запись — только по нажатию кнопки сохранения.

## Параметры

Эти поля относятся к проектному окну. У системного Сохранить как… папка и имя выбираются в стандартном окне операционной системы.

| Поле | Назначение |
|---|---|
| Файл проекта | Существующий JSON для перезаписи или вариант «Новый файл…» |
| Имя JSON-файла | Одно имя, без пути. Расширение .json добавляется автоматически |
| Строка назначения | Показывает путь относительно проекта и явно сообщает о перезаписи |
| Сообщение состояния | Загрузка, результат сохранения или причина отказа |

Пример: выберите `Видео-в-Хронику-по-этапам.json`, чтобы обновить наш поэтапный workflow; для эксперимента задайте `Видео-в-Хронику-мягкая-копия.json`.

Для варианта **Сохранить в workflows проекта** символические ссылки, подпапки и пути вне workflows не поддерживаются. Предел размера JSON — 16 MiB. Сервер принимает запись только от локального клиента через localhost/127.0.0.1 с той же origin. Все файлы относятся к папке проекта на машине сервера ComfyUI, а не к произвольной папке браузера на другом компьютере.

## Decision helper

- Нужно обновить файл в репозитории ALEXZ_tools: **Workflows проекта**.
- Нужно сохранить обычный пользовательский workflow: стандартный **Save / Ctrl+S**.
- Нужна произвольная папка и последующая запись в тот же файл: **Сохранить как…**, затем **Сохранить** в нашем разделе.
- Браузер не поддерживает системный диалог: стандартный **Export**, с запросом папки в настройках загрузок.

При первом сохранении выберите имя явно. Для того же открытого графа выбор запоминается до перезагрузки страницы. В сохранённый JSON добавляется `extra.alexz_project_workflow` с именем: после загрузки такого файла команда снова предлагает его имя. Это подсказка, а не автоматическая запись или разрешение сохранять в произвольный путь.

## Интерпретация выходов

Для системного сохранения успех подтверждается статусом в боковой панели и JSON в выбранной папке. Для проектного — сообщением в окне и JSON в папке workflows. После сохранения файл можно проверить через git diff и затем закоммитить обычным способом.

Звёздочка несохранённых изменений на вкладке ComfyUI может остаться: проектная запись не отмечает workflow как сохранённый в пользовательской библиотеке ComfyUI. Сообщение **«Сохранено»** относится именно к файлу проекта.

Для разработчиков: backend предоставляет GET/POST `/alexz/project-workflows`. GET возвращает имена и версии содержимого, POST принимает filename, workflow и expected_revision. JSON с форматом API prompt не принимается вместо обычного редакторского workflow.

## Типовые ошибки и решения

| Сообщение или ситуация | Что делать |
|---|---|
| Браузер не поддерживает системный диалог | Используйте Export с запросом папки в настройках загрузок или проектный вариант сохранения |
| Файл изменён другим приложением | Выберите его заново через Сохранить как… после проверки внешних изменений |
| Маршрут сохранения ещё не загружен | Перезапустите ComfyUI и обновите страницу, чтобы зарегистрировались новые маршруты |
| Файл изменился на диске или уже существует | Закройте окно, откройте снова для перечитывания версий и выберите файл повторно. Чужие изменения не перезаписываются автоматически |
| Активный workflow изменился | Откройте окно заново для нужного активного графа |
| Укажите только имя файла | Уберите путь и служебные символы; папка workflows уже выбрана сервером |
| Ошибка прав доступа | Проверьте возможность записи в workflows у пользователя, запустившего ComfyUI |
| После сохранения нет файла в output | Он сохранён в workflows ALEXZ_tools; output больше не участвует в этой операции |

Запись выполняется через временный файл и атомарную замену. Ошибка записи не оставляет наполовину записанный JSON; конфликт версии не меняет текущий файл. Встроенная проверка защищает от обычных параллельных сохранений через эту команду; она не заменяет контроль версий и согласование одновременной работы внешних редакторов.

## Производительность

Операция не запускает ноды и не обрабатывает видео. Чтение и запись файлов выполняются вне event loop ComfyUI. Существующие файлы хешируются при открытии окна и перед перезаписью для проверки версии; сохранение большого графа занимает больше времени, чем маленького примера.

Frontend: `frontend/src/project_workflows.ts` и `frontend/src/workflow_file_save.ts`, runtime bundle — `web/generated/project_workflows.js`. После изменения TypeScript нужны `make ts-check` и `make frontend-build`. Backend: `utils/project_workflows.py`.
